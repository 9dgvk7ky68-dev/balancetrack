# balancetrack

A polished PWA for tracking overtime (TTB) and days in lieu with offline support, local storage, and a dashboard-style interface.

## Run locally

1. Open the frontend folder:
   - cd balancetrack-source/frontend
2. Start a local server:
   - python3 -m http.server 8000
3. Visit:
   - http://127.0.0.1:8000

The app stores entries locally in the browser and can be installed as a standalone app on supported devices.
